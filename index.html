¡Hola! Soy Selecto, tu guía de consultas SQL.
Vamos a construir una base de datos con tres tablas. Después veremos cómo SELECT transforma esos registros en información útil.

Laboratorio de inserción: 3 tablas

Datos editables

Escribe una instrucción INSERT INTO para agregar registros. También puedes cargar datos de ejemplo. Las claves de ventas deben existir en clientes y productos.

INSERT INTO clientes (id_cliente, nombre, ciudad) VALUES (4, 'Marta', 'Luque');

Tablas de práctica: clientes(id_cliente, nombre, ciudad), productos(id_producto, nombre, precio), ventas(id_venta, id_cliente, id_producto, cantidad, fecha).
